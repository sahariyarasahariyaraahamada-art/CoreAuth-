One Plugin. Many Tools.

Installation Guide

Follow these basic steps to install CoreAuth.

1

Download CoreAuth

Download the CoreAuth 4.0.0 JAR file.

2

Open Your Server Folder

Locate the plugins directory of your server.

3

Install the Plugin

Place CoreAuth-4.0.0.jar inside the plugins folder.

4

Restart Your Server

Restart the server and check the plugin configuration.
